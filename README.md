# python-proj-negundo-Skrindievskiy
Программа, создающая наглядную инфографику, отображающую процесс инвазии биологического вида в Европейской части России (на примере клёна ясенелистного).  A program that creates clear infographics depicting the process of invasive species spread in the European Russia (using the boxelder as an example).
